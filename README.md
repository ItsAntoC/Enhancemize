## About

**Enhancemize** is a lightweight **Fabric** modpack for **Minecraft 26.3** focused on performance and small gameplay improvements.

It contains no content mods, so you can play on any world and keep the classic Minecraft experience.

## Download

- 📦 [Modrinth](https://modrinth.com/modpack/enhancemize)

## Features

- 🚀 **Performance:** modern optimization mods for higher FPS
- 🧩 **Quality of life:** minimap, [feature], [feature]
- 🎮 **Vanilla feel:** no new blocks, mobs, or progression changes
- 🔄 **Up to date:** updated for new Minecraft versions, keeping your settings when possible
- 🧱 **Fabric:** fast startup and wide mod compatibility

## Installation

1. Download and install the [Modrinth App](https://modrinth.com/app).
2. Search for **Enhancemize** and click **Install**.
3. Press **Play**.

Prefer another launcher? Download the `.mrpack` from the [Releases](RELEASES_URL) page and import it into a launcher that supports Modrinth packs (like Prism Launcher).

## Playing on servers

Works on most servers. Falling-Tree is the only mod that needs server support, so remove it before joining one.
